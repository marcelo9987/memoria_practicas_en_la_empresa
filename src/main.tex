    \section{Resumen}\label{sec:resumen}
    Este documento recoge las prácticas realizadas en la \textit{Free Software Foundation Europe} (FSFE),
    organización dedicada al fomento y la protección del software libre y abierto.
    El periodo permitió participar en el mantenimiento de la infraestructura tecnológica de la fundación,
    así como en el desarrollo y actualización de herramientas utilizadas por su equipo y la comunidad.

    Entre las principales tareas se incluyeron la mejora de los sistemas de protección de servidores,
    la actualización de servicios y dependencias, la migración de una API XML-RPC a una API REST,
    el despliegue de un servicio de gestión de podcasts y la adaptación de formularios y funcionalidades
    de la página web. También se desarrolló una herramienta de análisis estadístico de eventos y noticias
    y se elaboró documentación técnica para la configuración y el uso de servicios internos.

    Las prácticas fueron una oportunidad para aplicar y ampliar conocimientos de Linux, administración
    de sistemas, desarrollo web, automatización y seguridad informática. Asimismo, contribuyeron a reforzar
    competencias profesionales como el trabajo con metodologías ágiles, la coordinación con equipos
    multidisciplinares y la gestión de incidencias en entornos reales.
